# Oficina Prime — Landing Page

Landing Page desenvolvida para o **Desafio 01**, com foco em HTML5 semântico,
CSS3, acessibilidade, responsividade e publicação no GitHub Pages.

## 🚗 Sobre o projeto

A Oficina Prime é uma oficina mecânica fictícia criada para representar um
serviço automotivo moderno, transparente e profissional.

A Landing Page apresenta:

- Hero com chamada para ação;
- Sobre a oficina;
- Estatísticas;
- Três serviços;
- Galeria de imagens;
- Informações de contato;
- Footer com navegação.

## 🛠️ Tecnologias

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

**JavaScript não foi utilizado**, conforme as regras do desafio.

## ♿ Acessibilidade

O projeto utiliza:

- Estrutura semântica com `header`, `nav`, `main`, `section`, `article`,
  `figure`, `figcaption`, `address` e `footer`;
- Hierarquia de títulos;
- Textos alternativos descritivos nas imagens;
- Links com textos claros;
- `aria-label` quando necessário;
- `:focus` nativo do navegador preservado;
- Suporte a `prefers-reduced-motion`;
- Layout responsivo sem rolagem horizontal.

## 📱 Responsividade

A página foi planejada para três contextos principais:

- Desktop;
- Tablet;
- Smartphone.

Os layouts são adaptados por media queries no arquivo `css/style.css`.

## 🤖 Uso consciente da Inteligência Artificial

A Inteligência Artificial foi utilizada como ferramenta de apoio durante
o desenvolvimento, sem substituir a compreensão do código.

### Prompt utilizado

> Quero criar uma Landing Page para uma oficina mecânica fictícia usando
> apenas HTML5 e CSS3. O projeto deve ser semântico, acessível, responsivo
> e publicado no GitHub Pages. Não utilize JavaScript, CSS inline ou tag
> `<style>`. A página deve possuir header com navegação, hero com CTA,
> seção sobre, pelo menos três serviços, galeria de imagens, contato e
> footer. Quero uma identidade visual moderna, profissional e diferente
> de templates genéricos.

### Como a IA ajudou

- Organização inicial da estrutura da página;
- Brainstorming de conteúdo e identidade visual;
- Sugestões de boas práticas semânticas;
- Revisão de acessibilidade;
- Sugestões de responsividade;
- Revisão da organização do CSS.

As decisões finais de conteúdo, estrutura e código foram revisadas para
garantir que o projeto pudesse ser explicado durante a apresentação.
